01PoC Objectives and Training Approach

Help TELKOM testers install ixi-O, see key features in action and evaluate the MVP first-hand.

LG U+ will lead training and technical support; TELKOM counterparts will help coordinate and assist testers.

02App Installation and Onboarding

A. Installation using the latest SOP

Scan the QR code in LG U+’s latest SOP (on screen or in print). LG U+ will check the links before training.

  • Install both apps using the SOP QR code.
  • Allow permissions, disable unused-app restrictions and set ixi-O as the default phone app.
  • Confirm the phone number and finish setup.
  • Download all three on-device AI models.
  • Enable recording permissions and adjust battery optimisation.
Important: PoC-only app distribution

The MVP uses a test-distributed APK, so extra permissions and manual settings are needed. This is specific to the PoC—not the intended commercial experience. An official app-store release is planned to offer a simpler setup, subject to final implementation.

Key message for testers

Please evaluate the service separately from the temporary PoC installation steps.

B. Network conditions and installation time

At TELKOM head office, 160–190 MB downloads took about 10 minutes or longer over office Wi-Fi and local mobile data. Allow extra setup time.
